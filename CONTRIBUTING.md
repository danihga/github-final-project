# Contributing to the Simple Interest Calculator

All contributions are welcome, including bug reports, bug fixes, documentation improvements, enhancements, and ideas.

To report a bug, open a GitHub issue with the inputs you used, the result you expected, and the result you received.

To suggest an idea or enhancement, open an issue describing your proposal. To contribute a code or documentation change, fork the repository, create a branch for your change, and open a pull request explaining what you changed and why.
